Sleevebook: planejamento e andamento

Um álbum digital para catalogar sua coleção de cartas, com páginas que viram, grade configurável (2×2, 3×3, 4×4…) e cadastro carta por carta em cada slot. As fases v0.1, v0.2 e v0.3 estão desenvolvidas; veja abaixo o que está pronto, o que foi só parcialmente verificado e o que falta. Os mockups mais abaixo são o planejamento original.

O que mudou em relação ao plano

  • Sem Vite, TypeScript e Dexie: não há Node na máquina, então é JavaScript puro com módulos ES e uma camada própria de IndexedDB.
  • A busca de Pokémon tem reserva (TCGdex), porque a Pokémon TCG API respondeu com erro 502 em alguns testes.
  • O deploy no GitHub Pages ficou manual: o plano gratuito não oferece Pages para repositório privado.

Limitações e o que não foi verificado

  • Não verificado: o service worker não registrou no navegador embutido do app, então o uso offline precisa ser confirmado num Chrome normal.
  • O arrastar foi testado com eventos simulados, não com o mouse; no celular ele não funciona (toque).
  • No celular o livro mostra duas páginas e as cartas ficam pequenas.
  • Os dados ficam só no navegador: faça backup com Exportar.

  • Cadastrar carta por slot: nome, set, número, condição, quantidade, imagem

Telas de exemplo

Mockups navegáveis o suficiente para você reagir ao layout. O de configuração é interativo: mude linhas, colunas e páginas e veja a grade.

Como o álbum interativo funciona

A visualização de livro se resolve em três camadas. Já testei a primeira num protótipo local, que descartei para planejar antes.

1 · Folhas em 3D com CSS

Cada folha tem frente e verso (as páginas 1/2, 3/4…). Virar a folha é girar 180° em torno da lombada com transform: rotateY(-180deg), e backface-visibility: hidden esconde o lado de trás. Sem biblioteca, leve, e dá para colocar qualquer conteúdo dentro, inclusive a grade de slots.

2 · Tamanho que se adapta

O tamanho da página é calculado pela grade (63×88 de cada carta mais espaçamento) e escalado para caber na tela. Por isso 2×2 e 4×4 ficam bem em qualquer janela. Capa e contracapa centralizam o livro quando só uma página aparece.

3 · Slots clicáveis

Cada slot é identificado por página:linha:coluna. Clicar abre o cadastro. Brilho ao passar o mouse e leve elevação dão a sensação de carta no bolso.

Alternativa: biblioteca

Uma biblioteca de page-flip dá a dobra curva da folha (mais realista), com custo de menos controle sobre o conteúdo e o redimensionamento. Dá para começar em CSS e trocar depois se você quiser o efeito.

Modelo de dados

Album   { id, name, game, rows, cols, pages, createdAt }
Slot    { albumId, page, row, col, cardId?, notes? }
Card    { id, name, set, number, image, condition, qty, source, sourceId }
Wishlist{ id, cardRef, priority }

Separar Slot de Card permite mudar a grade sem perder dados e, no futuro, a mesma carta aparecer na lista da coleção e no álbum.
